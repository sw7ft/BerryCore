# BerryCore setup

```sh
setup
```

- Hub `http://127.0.0.1:8098/`
- Web app catalog `/apps`
- qpkg catalog `/packages`
- Default userland `/core`
- Settings `/settings` (themes + SW7FT)
- Manual `/manual` (hub branded; classic page at `/berrycore.html`)

Term49 login runs `setup boot` (server + hub notification). Disable with `BERRYCORE_SETUP_AUTO=0`.

Also: `homescreen`, `pins`, `settings homescreen-on`
