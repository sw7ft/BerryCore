# BerryCore v0.90.0 - Berry Browser Chromium (first beta)

I have been working on restoring browser functionality for BB10 for years and I am happy to release the first beta of Berry Browser (Chromium). Yes it is a .bar so you will need a rooted device. Good news: content_shell and a Term49 bin are also included to play with. I will make that better.

## Berry Browser (BAR)

- File: `BerryBrowserV3-3.0.2-build83.bar`
- Rooted device required
- Includes content_shell and a Term49 bin

Install the BAR on a rooted Passport / BB10 device, then open Berry Browser.

## :8080 viewer (qpkg)

```
qpkg install berry-remote
berryremote
# http://127.0.0.1:8080/
```

Needs the engine from the BAR or `qpkg install berry-browser`.

## Notes

Software raster on this QNX content_shell (EGL does not come up from Term49). Screenshot viewer, not VNC of the whole phone. Beta. Heavy sites take a while.
