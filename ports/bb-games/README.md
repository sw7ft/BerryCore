# BerryCore Games (bb-games)

HTML game menu on **port 8766** — same idea as `tools` on 8765.

## Install

Bundled in BerryCore, or:

```sh
qpkg install bb-games
```

## Usage

```sh
games          # start server
games status
games stop
```

Open `http://127.0.0.1:8766/` in berry-browser.

Autostart: `settings games-on`

## Games

BerryCraft, BerryFly, BerryBoat, BerryDig, BerryMoto, BerryMX (latest + older versions on the menu).
