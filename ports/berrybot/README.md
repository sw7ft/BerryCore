# Berry Bot Port

Command-line teaching assistant for Linux, QNX, bash, and BerryCore. Non-AI, SQLite knowledge base.

## Install

```bash
qpkg install berrybot
```

## Quick start

```bash
bot grep              # Search for grep
bot how to search     # Search by phrase
bot lessons           # List lessons
bot lesson bash-basics
bot help
```

## Data

Knowledge base: `$NATIVE_TOOLS/share/berrybot/berrybot.sqlite`

Full docs: `$NATIVE_TOOLS/share/berrybot/README.md`
