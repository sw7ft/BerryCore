# BerryCore v0.90.0 — Berry Browser Chromium (first beta)

I have been restoring browser functionality for BlackBerry 10 for years. This is the first public beta of **Berry Browser — Chromium**.

## Berry Browser (BAR)

- File: `BerryBrowserV3-3.0.2-build83.bar`
- **Rooted device required** (it is a `.bar`)
- Includes **content_shell** and a **Term49** bin to play with (that part will get better)

Install the BAR on a rooted Passport / BB10 device, then open Berry Browser.

## :8080 viewer (qpkg)

The Chromium remote view we built:

```
qpkg install berry-remote
berryremote
# http://127.0.0.1:8080/
```

Needs the engine from the BAR or `qpkg install berry-browser`.

## Notes

Software raster on this QNX `content_shell` (EGL init does not come up from Term49). Screenshot viewer, not VNC of the whole phone. Beta quality — expect load time on heavy sites.
