# BerryCore Games

HTML games menu. ES5, no build step. Served on **port 8766**.

```sh
games          # start
games status
games stop
```

Then open `http://127.0.0.1:8766/` in berry-browser.

| Game | Latest | Older |
|------|--------|-------|
| BerryCraft | `berrycraft-tp-3.html` | v2 |
| BerryFly | `berryfly-2.html` | v1 |
| BerryBoat | `berryboat-3.html` | v2, v1 |
| BerryDig | `berrydig-2.html` | v1 |
| BerryMoto | `berrymoto.html` | — |
| BerryMX | `berrymx-2.html` | v1 |

Autostart: `settings games-on`
