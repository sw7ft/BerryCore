# BerryCore v0.90.1 — qpkg remove / uninstall

You can take a port off the device now.

```
qpkg remove NAME
qpkg uninstall NAME
qpkg remove -y berry-remote
qpkg list
```

## What it deletes

Only files that belong to that port's zip (or the file list recorded at install). It does **not** delete BerryCore, `bin/qpkg`, `env.sh`, `VERSION`, or the bundled catalog zips.

Base packages (`sensors`, `gps`, … `replaces=core`) stay unless you pass `--force`.

`qpkg install` now writes `.qpkg/files/NAME.list` so the next remove is exact. Ports installed before this release still uninstall from the catalog zip listing.

Get this qpkg: `qpkg update` (needs `berrycore.zip` on this release) or copy `bin/qpkg` from the tree.
