# piano — Term49 sine piano

Plays sine notes via QSA (play-audio WAV fallback). Interactive `asdfghjkl` scale or `piano c4 e4 g4`.

```sh
qpkg install piano
piano
piano c4
piano scale
```

Built on xps (`bb10-kitchen-sink`) for **armle-v7**. Rebuild: `bash /root/ports/piano/build-piano-passport.sh`
