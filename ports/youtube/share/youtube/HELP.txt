YouTube Navigator for BB10
============================

Search and stream YouTube in the BB10 browser.
Runs on port 8070. No separate pytube install needed.

QUICK START
-----------
  youtube
  # Open http://localhost:8070 in the browser

  youtube -f   # Foreground / debug

NOTES
-----
- Uses berrycore Python (pytube bundled when available)
- Embed playback works without pytube
- Hard-refresh the browser after updates
