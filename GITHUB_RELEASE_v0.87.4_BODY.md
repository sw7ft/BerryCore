## BerryCore v0.87.4

BerryCore Games — HTML game menu, same pattern as `tools`.

### Added

- **`games`** on port **8766** — `games` / `games stop` / `settings games-on`
- Splash + BerryCraft, BerryFly, BerryBoat, BerryDig, BerryMoto, BerryMX
- **`qpkg install bb-games`** — `games-bb-games-1.0.zip` (also bundled in `berrycore.zip` under `packages/`)

### Use

```sh
games
berry-browser http://127.0.0.1:8766/
```
