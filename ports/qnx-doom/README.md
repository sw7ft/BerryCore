# QNX Doom port

Doom for BlackBerry Passport via X11 (XSDL required).

- **qpkg:** `qpkg install qnx-doom`
- **Source:** https://github.com/sw7ft/qnx-packages/tree/main/qnx_doom_deploy
- **Build:** `./build-port.sh [path-to-qnx_doom_deploy]`

Place `qnx_doom_deploy/` next to this README (clone from qnx-packages) before building.
