About the Library

BerryCore Library is an on-device shelf and reader. Books stay on the Passport. Nothing is uploaded to a cloud.

Reads well

  • EPUB — preferred. Chapters, covers, and in-book links.
  • FB2 — FictionBook. Common for public-domain libraries.
  • HTML / HTM / XHTML — a single page or saved article.
  • Markdown — headings and paragraphs.
  • Plain text — .txt / .text, split on blank lines.

Not yet — PDF, MOBI/AZW, DOCX, and comics (CBZ). Those need extra engines. Convert to EPUB or HTML for now, or drop a .txt.

Shelves are categories you can open, rename, reorder, and add. Tap a book’s gold chip to file it or remove it. Archive saves categories with the books.

The Bell Labs UNIX shelf starts with the Seventh Edition Volume 2 papers (the 1979 document set people still used when System III shipped in 1981) plus Dennis Ritchie’s essays. The Operating Systems shelf starts with MIT’s xv6 book. The famous trade books — K&R, Kernighan & Pike, Bach — are still in copyright, so they are not bundled.

Put files in /accounts/1000/shared/books, or use Import to copy from Documents and Downloads. Archive writes a zip of the shelf plus reading progress to Documents.
