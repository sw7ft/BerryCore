RocketChat Navigator for BB10
=============================

Web app for RocketChat private groups and direct messages.
Runs on port 8026.

INSTALL
-------
  qpkg install rocketchat

REQUIRES
--------
  python3 (qpkg install python3)

QUICK START
-----------
  rocketchat
  # Starts in background. Open http://localhost:8026 in BB10 browser

  rocketchat -f   # Run in foreground (for debugging)

FIRST-TIME SETUP
----------------
1. Run rocketchat
2. Open http://localhost:8026 in browser
3. Enter RocketChat server URL (e.g. https://your-server.com)
4. Enter username and password
5. Login - credentials saved to share/rocketchat/.env

FEATURES
--------
- Private groups and direct messages
- Search rooms
- Send messages
- Real-time refresh
- BB10 notifications (when configured)
