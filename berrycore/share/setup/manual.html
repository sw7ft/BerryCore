On-device setup

Type setup in Term49. That opens this hub in the BB10 Browser.

setup
# hub       http://127.0.0.1:8098/
# apps      http://127.0.0.1:8098/apps
# packages  http://127.0.0.1:8098/packages
# core      http://127.0.0.1:8098/core
# manual    http://127.0.0.1:8098/manual

Pin the hub from Browser → Add to Home Screen. Login: settings homescreen-on starts the hub only. Aliases: homescreen, pins.

Introduction

BerryCore is the QNX Extended Userland for BlackBerry 10 — a modern continuation of Berry Much OS.

Core bundle

~210 MB berrycore.zip — bash, vim 9.1, git, gcc, python-ready env. Installs to /accounts/1000/shared/misc/berrycore/.

Optional ports

qpkg install NAME downloads a port zip. Browse and install from Packages.

Default tools

What ships on the device is listed under Core. Same index as qpkg catalog and qpkg bins.

Install

Fresh device

  1. Copy berrycore.zip and install.sh to /accounts/1000/shared/misc/.
  2. In Term49 or SSH: 
    cd /accounts/1000/shared/misc
sh install.sh --fresh -y
. berrycore/env.sh
  3. Verify: 
    cat $NATIVE_TOOLS/VERSION
qpkg ports
vim --version

Upgrade

cd /accounts/1000/shared/misc
sh install.sh --upgrade -y
# or:
qpkg update

Install a port

qpkg search cab
qpkg show cabextract
qpkg install cabextract

Or tap Install on Packages.

Auto-start

settings sshd-on
settings tools-on
settings homescreen-on
settings status

How it works

berrycore.zip → install.sh → env.sh → qpkg for extra ports.

Layout

/accounts/1000/shared/misc/
├── berrycore/          ← NATIVE_TOOLS
│   ├── bin/            ← qpkg, vim, git, curl, …
│   ├── packages/       ← bundled zips
│   ├── env.sh
│   └── CATALOG
├── bin/                ← misc tools
└── share/              ← port docs, web UIs

Shell

After . berrycore/env.sh, $NATIVE_TOOLS/bin is on PATH.

setup
qpkg catalog
qpkg catalog -s vim
settings status

Shortcuts: bc · misc · docs · downloads · sdcard — no args cd, a name copies a file out.
