qnx-doom — Doom on QNX / BlackBerry Passport (X11)

REQUIRES XSDL or XServer — this is NOT a terminal game.
Includes Freedoom Phase 1 (freedoom1.wad) — ready to play.

Quick start:
  qpkg install qnx-doom
  # Start XSDL (APK in share/qnx-doom/apks/)
  qnx-doom
  # Press Enter at the Display prompt for 127.0.0.1:0

Run on device only — not over SSH.

No audio. Passport test build.

Manual: share/doc/qnx-doom/MANUAL.md
