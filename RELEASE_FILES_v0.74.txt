INSTALLATION
------------

On BlackBerry 10 device:

1. Download both files to /accounts/1000/shared/documents/
2. Run: sh install.sh
3. Follow prompts
4. Restart terminal or source env.sh

Or use qpkg update (if already have BerryCore installed)

WHAT'S NEW IN v0.74
-------------------

🌉 Term49Bridge-API
- Android runtime bridge for BB10
- Enables advanced permissions (audio recording, etc.)
- Located in: bar-files/Term49Bridge-API.apk
- Size: 79 KB

🌐 ELinks 0.17.0 (New Port)
- Text-based web browser
- SSL/TLS with bundled Mozilla CA certificates (225KB)
- Wildcard certificate support (*.example.com)
- JavaScript engine (QuickJS ES2020+)
- CSS rendering
- Install: qpkg install elinks

📱 BerryPy 2.1.0 (Upgraded)
- Smart app requirements system
- Pre-install requirement detection
- Setup instructions and notifications
- New apps: Telegram V7, RocketChat V3

📦 Port Count: 7 total
- apache-php (web, 43 MB)
- berrypy (web, 75 KB)
- berrysnip (util, 24 KB)
- elinks (web, 1.3 MB) ⭐ NEW - with SSL certificates
- hydra (net, 165 KB)
- python3 (lang, 25 MB)
- tmux (sys, 2.5 MB)
